# 复刻包说明

这个包只包含 **001–044 段**、从头复刻 APT 视频所需的素材和脚本。

- 002 全段没有人，不生成；组装时直接用原片。
- 004、007、017 按用户决定直接用原片，不替换、不提交、不写提示词。
- 其余 40 段需要按简介和模板现写提示词，再提交生成。

## 目录

- `补齐生成用\`：001–044 的源片（文件名带帧数）、同名中文简介、`原始帧数.txt`（前 44 段，合计 2316 帧）、`补齐后帧数.txt`（角色；004/007/017 标「原片」，002 标「没有人」）。
- `替换用参考图\`：`一号.png`、`二号.png`。
- `提示词\`：空目录。按简介和模板为 40 段现写。
- `完成分段\`：空目录。最终组装使用；独立候选由apt_runtime.py下载到candidates。
- `原片音轨.m4a`：从原 MV 抽出的 AAC 音轨（约 173.43 秒），组装时复制对应前96.5965秒AAC包。
- `rh_batch.py` / `assemble.py`：原包配置/来源参考；新执行入口为apt_runtime.py、assemble-reviewed.py，validate_prompts.py负责提示词检查。
- `总体使用规则.md` / `R2VA加强版提示词模板.md`：写提示词的规则和模板。
- `ai应用.txt` / `并发数.txt`：模式、实例、一采分辨率、并发数。
- `ffmpeg\`：保留第三方来源/许可说明；公共包不含可执行文件，使用本机FFmpeg/ffprobe。

## 步骤（安装版1.2）

1. 以目录外私有Key、当前两个身份图准备独立run；本次选择明确复用/对调时直接核对使用，不重复索图。
2. 读技能参考/production-and-review.md与原片真实连续帧，写本次40份提示词，更新当前外貌检查，validate_prompts.py需errors0。038、041按实测含边缘角色走双图。
3. 按技能参考/runtime-and-review-tools.md写不可变队列：apt_runtime.py prepare，完成语义与源动作审查后check、run。同账户唯一调度器3并发，所有已付费任务按原ID恢复。原rh_batch.py旧提交入口已停用。
4. 每个候选完整实际输出时钟和原尺寸逐帧查看；动作/切点对应原片，不把前置或尾部保持帧当真动作。不合格部分以三个不同方法比较修复，已通过段保留。
5. 40生成+4原片全部选定后，用assemble-reviewed.py及其前后检查工具组装2316帧、约96.5965秒，原AAC取对应前段，保持wuwukasi署名和许可；inspect-final-assembly.py核原音包前缀及准备43接点。
6. 分别记录技术、原尺寸、原动作、接点和整片原速状态。给出真实成片，未发生的播放不得写通过。

源片只到044。新可靠下载位于candidates，选择清单位于制作分析；原assemble.py仅作来源参考。运行工具需要Python av/Pillow，FFmpeg使用本机已安装或已有便携版本。素材简介里的旧人物外貌不覆盖当前参考图；原片事实高于旧简介。
